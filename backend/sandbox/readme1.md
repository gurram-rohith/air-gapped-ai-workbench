# 🛡️ Developer 4: Sandbox Execution & Dataset Infrastructure

> **Module Location:** `backend/sandbox/`  
> **Target Hardware:** 16 GB RAM Air-Gapped Laptops  
> **Core Focus:** Subprocess Code Isolation, Regex Pre-Filters, and Automated SOP PDF Generation  

---

## 1. Executive Summary & Hardware Limits

This module handles secure code execution and dataset initialization for the SIH 2026 AI Workbench. It receives Python math code generated by the LLM (Developer 3), screens it for safety risks, and executes it within an isolated environment.

To optimize for **16 GB RAM air-gapped developer laptops**, this sandbox completely avoids heavy virtualization (like Docker or VirtualBox). Instead, it uses lightweight **subprocess isolation** paired with **deterministic regex pre-screening**, delivering sub-100ms execution speeds with near-zero memory footprint.

---

## 2. Package Dependencies Manifest

The following Python packages and standard library modules comprise Developer 4's implementation scope:

| Package / Module | Source | Primary Purpose & Usage in Code |
| :--- | :--- | :--- |
| **`reportlab`** | External (`pip install reportlab`) | Generates 5 standardized policy PDF documents using Platypus (`SimpleDocTemplate`, `Paragraph`, `Table`) in `generate_sample_pdfs.py`. |
| **`pydantic`** | External (`pip install pydantic`) | Formats structured execution result payloads for API responses passed to Developer 5. |
| **`subprocess`** | Standard Library | Jailed child process execution with strict 10-second hard kill timeout limits (`executor.py`). |
| **`re`** | Standard Library | Pre-execution pattern screening to intercept forbidden imports and calls (`boundary_checks.py`). |
| **`uuid`** | Standard Library | Creates globally unique filenames (`temp_script_<UUID>.py`) to prevent race conditions during concurrent execution. |
| **`os` / `pathlib`** | Standard Library | File path management, directory creation (`data/documents/`, `data/temp_scripts/`), and automated script deletion in `finally:` blocks. |

## 3. Dual-Layer Security Architecture

```text
                     [ Incoming LLM Code ]
                               │
                               ▼
     ┌──────────────────────────────────────────────────┐
     │ Layer 1: boundary_checks.py                      │
     │ Regex AST pre-screen for blacklisted imports     │
     └──────────────────────────────────────────────────┘
                               │ (Passed)
                               ▼
     ┌──────────────────────────────────────────────────┐
     │ Layer 2: executor.py                             │
     │ Jailed subprocess.run(..., timeout=10)           │
     │ Auto-cleans UUID script in finally: block       │
     └──────────────────────────────────────────────────┘
                               │
                               ▼
                    [ Validated Standard Output ]
